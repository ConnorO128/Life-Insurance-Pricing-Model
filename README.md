# Life Insurance Pricing Model

Financial modeling project analyzing insurance pricing, reserves, IRR, and sensitivity scenarios.

## Overview

This project compares a **Level Premium Term Insurance** product and a **Yearly Renewable Term (YRT)** product using a multi-sheet Excel financial model. The model evaluates profitability, statutory reserves, distributable earnings, and risk-adjusted returns under varying actuarial assumptions.

The workbook was built to simulate insurance cash flows and assess how changes in mortality, lapse rates, and interest assumptions affect long-term profitability.


## Model Features

- Level Premium and YRT pricing structures
- Statutory income statement projections
- Statutory reserve calculations
- Mortality and lapse assumptions
- Commission and maintenance expense modeling
- IRR and distributable earnings analysis
- One-way sensitivity testing
- Two-way scenario analysis


## Key Inputs

- Number of policies sold
- Average face amount
- Earned interest rate
- Mortality assumptions
- Lapse assumptions
- Expense assumptions
- Commission structure
- Tax rate


## Analysis Performed

The project evaluates how profitability changes under different assumptions, including:

- Changes in earned interest rates
- Mortality stress scenarios
- Lapse rate sensitivity
- Reserve impacts on distributable earnings
- Risk-adjusted IRR comparisons between products


## Workbook Structure

### Section 1 — Input Assumptions
Contains pricing, mortality, lapse, commission, and expense assumptions.

### Section 2 — Intermediate Calculations
Projects policies in force and face amount over time.

### Section 3 — Statutory Income
Calculates premiums, benefits, expenses, taxes, reserves, and after-tax income.

### Section 4 — Statutory Reserves
Projects reserve requirements using statutory mortality assumptions.

### Sensitivity Testing
Performs one-way and two-way scenario analysis on key risk factors.

## Key Takeaways

- Level Premium products generated higher baseline risk-adjusted IRRs.
- Profitability was highly sensitive to mortality and earned interest assumptions.
- Reserve requirements had a significant impact on distributable earnings.
- Sensitivity testing demonstrated how small assumption changes materially affect long-term results.
